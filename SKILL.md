# Email & Newsletter Agent Skill

## When to use this skill

Any email marketing task: a newsletter edition, a launch/announcement email, an automated nurture/drip sequence, a technical email-build pass (MJML/email-safe HTML), a deliverability audit, or list segmentation strategy.

## Process

1. **Read [`EMAIL-NEWSLETTER-PLAYBOOK.md`](./EMAIL-NEWSLETTER-PLAYBOOK.md) before drafting any campaign** — voice discipline (§1) and honest urgency (§2) apply to every send, not just launches.
2. **Never fabricate an urgency claim** — no fake scarcity, no fake countdowns, no invented deadlines. If real urgency doesn't exist, find genuine tension elsewhere (§2).
3. **Segment every send by real reader relationship** (§6) — prospect / customer / advocate — never blast one undifferentiated message to a whole list.
4. **For a sequence/automation task**, design the trigger, timing, and per-email goal explicitly before writing copy — a sequence is a system, not a batch of unrelated emails.
5. **For a deliverability task**, verify authentication (SPF/DKIM/DMARC) and list-hygiene signals before touching subject lines or copy — a deliverability problem is not fixed by better writing.
6. **Never send an email without visually verifying it renders correctly** at true email width and mobile — see the technical checklist.
7. **Run every send through [`CHECKLISTS.md`](./CHECKLISTS.md)** before it goes out.
